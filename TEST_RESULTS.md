# Schema Title Sanitization - Test Results

## Problem Fixed
Tools from apps were getting bad auto-generated titles like `"tl@714-1066"` in their input schema properties. These titles were generated by the TypeScript-to-JSON-Schema converter based on source code positions (Type Location @ line-char positions).

## Solution Implemented
Added `sanitizeSchemaTitle()` function in `/Users/abdul/Developer/deco-mcp/utils.ts` that:
- Recursively removes all titles matching the pattern `/^\[?tl@\d+-\d+\]?$/`
- Preserves all good, human-readable titles
- Works on all schema structures (properties, items, anyOf, oneOf, allOf, definitions)
